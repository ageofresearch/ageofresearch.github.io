Formal target

For a nonempty integer partition, define its perimeter as the largest part plus the number of parts minus one. Let FO j k n count perimeter-n partitions having exactly j distinct present part sizes divisible by k. Let FD j k n count those having exactly j distinct part sizes whose multiplicity is at least k.

Public declaration 01 FixedPerimeter.fixedPerimeter_eq_two

For every natural j and n, FD j 2 n = FO j 2 n.

Public declaration 02 FixedPerimeter.fixedPerimeter_ratio_tendsto_zero

For fixed j and k ≥ 3, the real sequence FO / FD tends to zero.

Public declaration 03 FixedPerimeter.fixedPerimeter_eventually_strict

For fixed j and k ≥ 3, there is a threshold after which FO < FD.

The quotient in the limit theorem is formed in the real numbers. The quantifiers fix j and k before the limit in n; no uniformity in either parameter is claimed.

Definitions and boundaries

Finite representation

A partition at perimeter index n is a nonzero bounded multiplicity vector on part sizes 1 through n.

Distinct sizes

Both statistics count supported part sizes—not total occurrences or excess multiplicity.

Boundary at n = 0

The empty multiplicity vector is excluded, so both counts are zero. The k = 2 equality includes this case.

Natural subtraction

Nonemptiness supplies positive largest part and part count, making the perimeter identity safe on counted objects.

The complete author-prepared semantic map is available in STATEMENT_MAPPING.md. It is documentation, not an independent semantic review.

Proof architecture

  1. 01

    Executable finite model

    Bounded multiplicity vectors define perimeter, both statistics, and concrete finite counts. Bridge modules connect them to canonical fibers.

  2. 02

    Exact k = 2 correspondence

    A recursive map adapted from Lin–Xiong–Yan is formalized together with its inverse, perimeter preservation, and an additional support-statistic identity.

  3. 03

    Generating functions

    Fixed-j formal power-series identities are derived from the finite combinatorial definitions rather than assumed.

  4. 04

    Dominant-root analysis

    The development proves positive roots, simplicity, complex minimum-modulus uniqueness, and the strict root comparison for k ≥ 3.

  5. 05

    Coefficient asymptotics

    A claim-specific rational transfer argument controls non-dominant terms and establishes positive leading constants.

  6. 06

    Final comparison and transport

    Positive asymptotic equivalents yield the ratio limit and eventual positivity needed for strict inequality, then transport the conclusions back to executable FO and FD.

Clean reproduction

Clone the repository, enter the pinned Lean project, obtain the Mathlib cache, and run the full build and audit:

shell
git clone https://github.com/ageofresearch/formagization.git
cd formagization/formalizations/fixed-perimeter-partitions/lean4
lake exe cache get
lake exe mk_all --check
lake build FixedPerimeter
lake env lean FixedPerimeter/AxiomAudit.lean
