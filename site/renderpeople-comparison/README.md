# Renderpeople comparison gallery

Public presentation of the two completed Blender reference projects, at `/renderpeople-comparison/`.

Only direct rendered PNGs and a rendered H.264 playback excerpt are published. No raw models, source textures, geometry caches, Blender files, or private delivery archives are included. Source models are licensed by Renderpeople; obtain them from the publisher's official free-samples page. The repository's code license does not relicense Renderpeople's source assets.

The comparison is explicitly partial: the Posed People Plus sample is an adult male reference and the 4D sample is Aliyah, a female subject. They are different individuals. The page discloses estimated stature and capture limitations.

The PNGs and MP4 are copied byte for byte from the validated Blender output. Page code has no external dependencies, analytics, or embedded credentials. `gallery.js` synchronizes the two inspection views and provides an accessible native dialog for enlargement; the video uses native playback controls.
