# Aristotle submission archive

This directory is the public, append-oriented evidence archive generated by the
Formagization Aristotle workspace.

- `successes/` contains runs whose authoritative terminal Aristotle task status
  is exactly `COMPLETE`.
- `failures/` contains every other terminal run, including
  `COMPLETE_WITH_ERRORS`, `OUT_OF_BUDGET`, `FAILED`, and `CANCELED`.
- The GitHub Pages interface reads only `successes/index.json`; failure records
  remain accessible in this public repository but are not listed on the site.

Each project directory may contain:

- `metadata.json` — normalized provenance, terminal state, hashes, and inventory.
- `prompt.txt` — the exact submitted request or imported public conversation.
- `status-history.jsonl` — sanitized progress snapshots observed by the client.
- `archive-log.jsonl` — sanitized archival events.
- `result.tar.gz` — the result returned by Aristotle, when available and within
  GitHub’s practical file-size limit.

Neither the Aristotle API key nor the server-side GitHub credential is written
to these files.
